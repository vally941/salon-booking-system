# 💇🏽‍♀️ Vally's Divine Hair – Salon Booking System

A full-stack salon booking web application developed using Flask and MySQL.

The system allows customers to book appointments online while administrators manage services, bookings, and customer records through a secure dashboard.

---

## 📌 Project Overview

This application was developed to demonstrate:

- Full-stack web development
- Backend logic implementation using Flask
- Relational database integration with MySQL
- Authentication and secure session handling
- Role-based admin access control

---

## 🛠️ Technologies Used

- Python 3
- Flask
- Flask-SQLAlchemy
- MySQL (XAMPP)
- PyMySQL
- HTML5
- CSS3
- JavaScript
- Cryptography
- Python-dotenv

---

## 🗄️ Database Configuration

The system connects to a MySQL database:

mysql+pymysql://root:@localhost/hair_salon_db

The application uses:

- SQLAlchemy ORM
- Relational database design
- Structured tables for users, services, and appointments

## 🚀 Installation Guide

1️⃣ Clone the repository:

git clone https://github.com/vally941/hair-appointment-site.git

2️⃣ Install dependencies:

pip install -r requirements.txt

3️⃣ Ensure MySQL (XAMPP) is running

4️⃣ Create the database:

hair_salon_db

5️⃣ Run the application:

python app.py

6️⃣ Open in your browser:

http://127.0.0.1:5000
